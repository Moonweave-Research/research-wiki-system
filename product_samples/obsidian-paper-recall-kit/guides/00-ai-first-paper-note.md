# AI로 10분 안에 첫 논문 노트 만들기

처음부터 빈 노트를 채우려고 하지 마세요. 논문 제목, 초록, 읽으면서 적은 메모를
AI에게 넣고 회수 단서만 뽑은 뒤, Obsidian에는 줄인 결과만 남깁니다.

## 준비할 입력

- 논문 제목, 저자, 연도
- 초록 또는 introduction 일부
- 내가 밑줄 친 문장 3개에서 5개
- 왜 이 논문을 읽었는지 한 줄

## 1. Paper note 초안 받기

```text
이 논문을 Obsidian 연구 위키용 paper note 초안으로 바꿔줘.
목표는 긴 요약이 아니라 나중에 다시 찾는 것이다.

아래 항목만 짧게 작성해줘.
1. 한 줄 기억
2. 왜 읽었나 후보
3. 나중에 찾을 키워드 5개
4. 연결할 개념 후보 3개
5. 주장/방법/결과 각 1줄
6. 다시 볼 이유 후보 2개
7. 질문 노트 제목 후보 3개

모르는 내용은 추측하지 말고 비워둬.
```

## 2. 붙이기 전에 줄이기

AI가 만든 문장을 그대로 붙이면 노트가 금방 비슷해집니다. 아래 기준으로 줄인 뒤 붙입니다.

| 항목 | 남기는 기준 | 버리는 기준 |
| --- | --- | --- |
| 한 줄 기억 | 논문의 역할이 보인다 | 그냥 좋은 논문이라는 말이다 |
| 키워드 | 내가 실제로 검색할 말이다 | 너무 일반적인 분야명이다 |
| 개념 후보 | 다른 논문도 붙일 수 있다 | 이 논문에만 있는 표현이다 |
| 다시 볼 이유 | 미팅, 리뷰, 실험 설계 상황이 있다 | AI가 만든 일반론이다 |

## 3. Concept note 후보 고르기

```text
위 paper note에서 concept note로 만들 만한 항목을 5개 추천해줘.
각 항목을 이론, 방법, 사례, 장치, 데이터셋, 현상 중 하나로 분류해줘.
너무 넓은 말은 제외하고, 나중에 여러 논문을 모을 수 있는 개념만 골라줘.
```

AI가 후보를 많이 줘도 1개에서 3개만 고릅니다.

## 4. Question note 후보 고르기

```text
이 논문을 제목 없이 다시 찾는다고 가정하고,
내가 검색할 법한 질문 제목 5개를 만들어줘.
각 질문은 Obsidian 노트 제목으로 쓸 수 있게 짧게 써줘.
너무 논문 제목처럼 쓰지 말고 실제 미팅에서 나올 말처럼 써줘.
```

질문 노트는 논문마다 만드는 메모가 아닙니다. 제목을 잊어도 그 질문으로 다시
찾을 것 같은 것만 남깁니다.

## 5. 최종 체크

```text
아래 Obsidian 논문 노트를 점검해줘.
새 요약을 쓰지 말고, 빠진 항목만 체크해줘.

확인할 것:
- 한 줄 기억이 구체적인가?
- 키워드가 실제 검색어처럼 보이는가?
- 연결 개념이 1개에서 3개인가?
- 다시 볼 이유가 내 연구 상황과 연결되는가?
- 질문 노트 후보가 논문 제목이 아니라 질문 형태인가?
```

AI가 마지막 판단자가 아닙니다. 최종 링크와 다시 볼 이유는 직접 고칩니다.
