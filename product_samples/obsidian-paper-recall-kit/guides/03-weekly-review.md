# 주간 회고 Workflow

논문 정리 시스템은 매일 완벽하게 관리하지 않아도 됩니다. 대신 일주일에 한 번,
연결이 끊긴 노트를 정리합니다.

아래 예시는 LCE/soft robot 분야지만, 회고 기준은 분야와 상관없이 같습니다.

## 15분 회고

매주 금요일 또는 미팅 전날 15분만 씁니다.

## 1. 이번 주 논문 노트 보기

이번 주에 만든 `papers/` 노트를 엽니다.

각 노트에 아래 항목이 있는지 확인합니다.

- 한 줄 기억
- 연결할 개념 1개 이상
- 다시 볼 이유
- 질문 1개 이상 optional

없으면 그 자리에서 한 줄만 추가합니다. 여러 노트를 한꺼번에 점검할 때는 AI에게 누락 항목만
찾게 하면 편합니다.

```text
아래 논문 노트들을 보고 빠진 항목만 체크해줘.
확인할 항목은 한 줄 기억, 연결 개념, 다시 볼 이유, 질문 후보야.
새 요약은 쓰지 말고 보완할 항목만 알려줘.
```

## 2. 비어 있는 개념 노트 채우기

Obsidian graph에서 링크는 걸려 있지만 내용이 없는 개념 노트를 찾습니다.

예:

```text
[[Thermal Actuation]]
```

처음에는 세 줄만 채워도 됩니다. 빈 개념 노트가 많으면 AI에게 세 줄 초안만 받습니다.

```md
# Thermal Actuation

## 핵심
열 변화로 재료의 형태나 운동을 제어하는 구동 방식.

## 관련 논문
- [[2020-christianson-lce-underwater-soft-robot]]

## 같이 볼 개념
- [[Liquid Crystal Elastomer]]
- [[Soft Robot]]
```

## 3. 필요하면 질문 노트 하나 업데이트하기

이번 주 미팅에서 나올 법한 질문 하나를 고릅니다.

질문 노트에 관련 논문 링크를 1-3개만 붙입니다.

```text
이번 주 논문 노트 목록을 보고, 다음 미팅에서 나올 법한 질문 5개를 추천해줘.
각 질문마다 연결하면 좋은 논문 노트 제목도 같이 적어줘.
```

```md
# LCE로 underwater robot을 만든 논문은?

## 바로 볼 논문
- [[2020-christianson-lce-underwater-soft-robot]]

## 같이 볼 개념
- [[Liquid Crystal Elastomer]]
- [[Soft Robot]]
```

## 4. 다음 주에 찾고 싶은 것 남기기

마지막으로 다음 주에 찾고 싶은 질문을 하나 씁니다. 꼭 별도 질문 노트로 만들 필요는
없고, 다음 읽기의 출발점으로 남기면 됩니다.

```md
- LCE actuator와 dielectric elastomer actuator를 비교한 논문은?
```

다른 분야라면:

```md
- 모델 크기와 데이터 크기 중 무엇이 성능에 더 중요한가?
- in vivo delivery 효율을 높인 방법은?
- 플랫폼 노동자의 자율성은 어떻게 측정했나?
```

다음 주의 읽기는 이 질문에서 시작합니다.

## 회고의 기준

좋은 주간 회고는 노트를 많이 고치는 시간이 아닙니다.

좋은 회고는 이렇게 끝납니다.
