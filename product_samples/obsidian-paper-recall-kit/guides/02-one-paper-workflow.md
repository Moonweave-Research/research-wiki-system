# 논문 1편 정리 흐름

## 원칙

논문 노트는 요약문이 아닙니다. 다시 찾기 위한 단서입니다.

완벽하게 정리하려고 하면 오래 못 갑니다. 대신 AI로 아래 다섯 칸의 초안을 받고,
내가 실제로 쓸 말만 남깁니다.

예시는 LCE/soft robot 논문이지만, 같은 흐름은 AI/CS, 생명과학, 인문사회 논문에도
그대로 적용됩니다.

1. 한 줄 기억
2. 나중에 찾을 키워드
3. 연결할 개념
4. 내가 다시 볼 이유
5. 다음 질문 optional

## 1단계. 제목과 출처 남기기

논문 제목, 저자, 연도, DOI 또는 Zotero key를 남깁니다.

```md
# 논문 제목

- year: 2020
- authors: Christianson et al.
- zotero: christianson_lce_underwater_2020
- doi:
```

정확한 citation은 나중에 정리해도 됩니다. 처음에는 다시 찾을 수 있을 정도면 됩니다.
Zotero를 쓰는 경우에는 key나 item link를 남기고, 운영형으로 발전시키면 source path와
PDF 위치까지 함께 남길 수 있습니다.

## 2단계. 한 줄 기억 쓰기

이 논문을 다시 떠올리게 해주는 문장을 하나 씁니다. 처음 문장은 AI에게 후보를 받으면 편합니다.

좋은 예:

```text
LCE 필름의 열 반응으로 물속에서 주기적 굽힘 운동을 만든 soft robot 논문.
```

나쁜 예:

```text
Liquid crystal elastomer에 대한 좋은 논문.
```

좋은 한 줄 기억은 논문의 역할을 말합니다.

```text
이 논문을 한 문장으로 기억해야 한다면 어떻게 쓰면 좋을까?
논문의 주제 말고, 내 연구에서 다시 볼 이유가 드러나게 3개 후보를 써줘.
```

## 3단계. 검색 키워드 남기기

나중에 내가 검색할 것 같은 단어를 적습니다. AI가 뽑아준 키워드에서 실제로 내가 쓸 말만 남깁니다.

```md
- liquid crystal elastomer
- underwater locomotion
- thermal actuation
- soft robot
```

논문에 나온 공식 용어보다 내 머릿속에 떠오를 단어가 더 중요합니다.

```text
이 논문을 나중에 다시 찾을 때 쓸 검색어를 8개 추천해줘.
공식 용어와 내가 검색할 법한 쉬운 표현을 섞어줘.
```

## 4단계. 개념으로 연결하기

논문이 연결되는 개념을 `[[...]]`로 남깁니다. AI가 많이 추천해도 1개에서 3개만 고릅니다.

```md
- [[Liquid Crystal Elastomer]]
- [[Soft Robot]]
- [[Thermal Actuation]]
```

개념 노트가 아직 없어도 괜찮습니다. Obsidian에서는 먼저 링크를 걸고 나중에 만들 수 있습니다.

다른 분야 예시:

```md
AI / CS:
- [[Scaling Law]]
- [[Evaluation Benchmark]]

생명과학:
- [[Gene Delivery]]
- [[Immune Response]]

인문사회:
- [[Gig Economy]]
- [[Survey Method]]
```

## 5단계. 다시 볼 이유 남기기

이 논문을 왜 다시 볼지 적습니다. 이 부분은 AI가 후보를 줄 수 있지만, 최종 문장은 직접 고칩니다.

```text
LCE 기반 구동 메커니즘을 설명할 때 참고.
soft robot actuator 예시가 필요할 때 다시 보기.
```

이 칸이 없으면 노트가 쌓여도 다시 열 이유를 잊습니다.

```text
이 논문을 몇 주 뒤 다시 열 만한 상황을 3개 제안해줘.
미팅, 리뷰 논문 작성, 실험 설계, 비교표 작성 같은 실제 연구 상황으로 써줘.
```

## 6단계. 필요하면 질문으로 바꾸기

마지막으로 질문을 하나 만듭니다. 논문마다 억지로 만들 필요는 없습니다. 제목을 잊어도
그 질문으로 다시 찾을 것 같을 때만 만듭니다.

```md
## 다음 질문

- [[LCE로 underwater robot을 만든 논문은?]]
- [[Thermal actuation을 쓰는 soft robot 예시는?]]
```

질문 노트는 연구자가 실제로 다시 떠올리는 문장에 가깝게 씁니다.

AI를 쓴다면 이 단계에서 질문 후보만 받아도 됩니다.

```text
이 논문을 나중에 다시 찾을 질문 제목 3개로 바꿔줘.
논문 제목을 그대로 쓰지 말고, 연구자가 실제로 검색할 말로 써줘.
```

## 15분 제한

논문 1편을 처음 정리할 때 15분을 넘기지 마세요.

15분 안에 안 끝나면 요약이 아니라 독후감을 쓰고 있을 가능성이 큽니다. 이 가이드의 목표는
논문 전체를 보존하는 것이 아니라, 다시 돌아오는 길을 만드는 것입니다.
