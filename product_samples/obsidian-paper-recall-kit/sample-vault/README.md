# 예시 Vault

이 폴더는 배포형 starter vault에서 어떤 노트를 만들게 되는지 보여주는 예시입니다.
운영형 Research Wiki 전체를 그대로 복사한 구조는 아닙니다.
예시는 LCE/soft robot 분야입니다. 특정 분야 전용이라는 뜻은 아니고, 실제감 있는
샘플을 보여주기 위한 것입니다.

## 둘러보는 순서

1. `papers/2020-christianson-lce-underwater-soft-robot.md`를 엽니다.
2. `연결할 개념`에서 `Liquid Crystal Elastomer`로 이동합니다.
3. 개념 노트의 `관련 논문`에서 다시 논문으로 돌아옵니다.
4. 선택형 예시로 `questions/LCE로 underwater robot을 만든 논문은.md`를 열어 질문에서 논문으로
   돌아가는 흐름을 봅니다.
5. 선택형 예시로 `meetings/2026-06-09-lab-meeting.md`를 열어 미팅 노트에서 논문과 질문이 어떻게
   이어지는지 봅니다.

## 볼 포인트

이 예시는 논문을 많이 정리한 vault가 아닙니다. 논문 1편이 여러 경로로 다시
찾아지는 구조를 보여주는 최소 예시입니다.

좋은 시작점은 큰 시스템이 아니라, 다시 찾을 수 있는 논문 1편입니다.

다른 분야라면 같은 구조에서 이름만 바꾸면 됩니다.

| 분야 | 개념 노트 | 질문 노트 |
| --- | --- | --- |
| AI / CS | Scaling Law | 모델 크기와 데이터 크기 중 무엇이 성능에 더 중요한가? |
| 생명과학 | Gene Delivery | in vivo delivery 효율을 높인 방법은? |
| 인문사회 | Gig Economy | 플랫폼 노동자의 자율성은 어떻게 측정했나? |

## AI로 따라 해보기

이 예시 파일을 처음부터 모두 손으로 만들 필요는 없습니다. 논문 제목, 초록, 읽으면서
남긴 메모를 AI에게 넣고 아래 항목의 초안을 받은 뒤, 링크와 다시 볼 이유만 직접 고치면 됩니다.

```text
이 논문을 sample vault처럼 정리해줘.
paper note, concept note, question note 초안을 만들어줘.
긴 요약보다 한 줄 기억, 키워드, 연결 개념, 다시 볼 이유, 질문 제목을 우선해줘.
```
