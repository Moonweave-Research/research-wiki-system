# Obsidian Research Wiki 스킬화 프롬프트 키트

내 Obsidian 연구 위키를 Codex 또는 Claude Code가 불러 쓸 수 있는 AI 에이전트 스킬로 바꾸기 위한 프롬프트 키트입니다.

전편에서 Obsidian Research Wiki 구조를 만들었다면, 이번 키트는 그 다음 단계입니다.
이미 있는 볼트를 새로 갈아엎기보다, AI가 그 구조를 읽고 사용할 규칙을 `SKILL.md`로 묶게 합니다.

공식 배포 링크: https://research-wiki-skill-kit.pages.dev/

이 자료는 Moon (@phd.ai.log)의 DM 무료 배포용 자료입니다. 개인 사용과 내부 공유는 가능하지만, 파일 재업로드, 유료 재판매, 출처 삭제, 자기 자료처럼 재배포하는 것은 허용하지 않습니다. 자세한 조건은 `LICENSE.md`를 확인하세요.

## 사용 전 확인

- 이 키트는 로컬 파일을 읽을 수 있는 Codex 또는 Claude Code 같은 에이전트 환경을 기준으로 합니다.
- 일반 채팅창처럼 내 컴퓨터 파일에 접근할 수 없는 환경에서는, 폴더 트리와 예시 노트를 직접 붙여넣어야 합니다.
- 비공개 연구 노트, 미공개 아이디어, 개인정보가 들어 있는 볼트라면 사용 중인 AI 도구의 데이터 처리 정책을 먼저 확인하세요.
- 이 키트는 검색 엔진이나 데이터베이스를 새로 만드는 자료가 아니라, 기존 볼트를 AI가 더 일관되게 찾아보도록 하는 스킬 작성용 프롬프트입니다.

## 사용 순서

1. `01_main_prompt.md`를 Codex 또는 Claude Code에 붙여넣습니다.
2. 내 Obsidian 볼트 경로를 알려줍니다.
3. AI가 볼트 구조를 확인한 뒤 `SKILL.md`를 만들게 합니다.
4. `02_qa_prompt.md`로 만든 스킬을 검토합니다.
5. `03_test_prompt.md`로 실제로 쓸 만한지 테스트합니다.

## 핵심 목표

- 내 노트 구조를 AI가 먼저 파악하게 하기
- 논문 노트, 아이디어 노트, 질문 노트, 정리 노트를 구분하게 하기
- 답변할 때 근거 파일을 남기게 하기
- 저장된 내용과 AI 추론을 섞지 않게 하기
- 과한 자동화 없이 바로 쓸 수 있는 최소 스킬부터 만들기
- 실제 파일 산출물은 우선 `SKILL.md` 하나로 제한하기
