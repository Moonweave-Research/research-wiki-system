# 테스트 질문 생성 프롬프트

스킬을 적용한 뒤, 아래 프롬프트로 테스트 질문을 만들고 실제로 몇 개를 실행해보세요.

```text
방금 만든 Obsidian Research Wiki 스킬이 제대로 작동하는지 확인할 테스트 질문을 만들어줘.

조건:

- 쉬운 검색 질문 3개
- 실제 노트 여러 개를 비교해야 하는 질문 3개
- 근거 부족을 확인하는 질문 2개
- AI가 함부로 단정하면 안 되는 함정 질문 2개

각 질문마다 아래 항목을 함께 적어줘.

- 질문
- 이 질문이 테스트하는 기능
- 좋은 답변의 기준
- 실패한 답변의 징후

특히 다음을 확인하고 싶습니다.

- 실제 파일을 찾는지
- 근거 파일 경로를 남기는지
- 논문 내용과 내 메모를 구분하는지
- 없는 내용을 만들어내지 않는지
- 검색 결과가 부족할 때 부족하다고 말하는지
```
